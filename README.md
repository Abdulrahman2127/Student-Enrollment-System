# 🎓 Student Enrollment System

A simple web-based Student Enrollment System developed as part of a university Web Programming assignment.

The project demonstrates the integration of frontend technologies with PHP backend processing to create an interactive student registration and login experience.

## 🚀 Live Demo

**Website:** https://abdulrahman.free.nf/StudentEnrollment/

## 🛠️ Technologies Used

- **HTML5** – Page structure and forms
- **CSS3** – Styling and layout
- **Bootstrap** – Responsive interface components
- **JavaScript** – Client-side validation and interactivity
- **PHP** – Server-side form processing and validation

## ✨ Features

- Student registration form
- Client-side form validation using JavaScript
- Server-side validation using PHP
- Student login form
- Login credential verification
- Password generation
- Responsive user interface

## 💻 How to Run Locally

1. Install XAMPP.
2. Start the Apache server.
3. Copy the project folder into `C:\xampp\htdocs\`.
4. Open your browser.
5. Visit:

   `http://localhost/StudentEnrollment/`

PHP files require a PHP-enabled server and cannot be executed directly by opening them as local files.

## 🎯 Project Purpose

This project was created to practice fundamental web programming concepts, including HTML forms, CSS styling, JavaScript validation, PHP form handling, and the interaction between client-side and server-side technologies.

## 📌 Notes

This is an educational project intended for demonstration and learning purposes. It is not a production-ready student management or authentication system.
